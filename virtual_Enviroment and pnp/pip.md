pip — package installer
What: The tool that downloads and installs Python libraries (packages).
How to use: pip install numpy
Where to find install commands: On any library's official site (PyPI, docs), there's a one-line pip install <name> — just copy-paste into terminal. 
Other useful commands:
pip list — show installed packages
pip freeze > requirements.txt — save your package list
pip install -r requirements.txt — install from that list
